# Song practice maps — 60 references

Research date: 2026-10-04. These are original, simplified one/two-bar drum-set practice loops inspired by the referenced recordings. They omit whole-song structure and do not claim exact transcription. The written lane recipes are in `src/domain/songMaps.ts`; sourced metadata is in `songMetadata.json`.

Tempos are approximate. Catalog analyses sometimes report half/double pulse; each conversion below is explicit. A linked live version may drift or differ from the catalog recording: use Tap tempo. BPM is quarter notes except the dotted-quarter 6/8 exercises. In 7/4 → 7/8 adaptations, quarter BPM is halved so seven eighths last as long as the original seven quarters. This is a teaching adaptation, not a claim that Money/Solsbury Hill/Spoonman are originally 7/8 or Balkan folk tunes. The 6/8 bank includes compound jazz/rock exercises; those recipes omit the African bell timeline that is absent from those songs.

Sources prioritize available notation/analysis, supplemented by SongBPM/GetSongBPM tempo catalogs. Primary examples include [Figure It Out notation](https://www.drumstheword.com/pdf/RoyalBlood_FigureItOut.pdf) and [Jazzomat Footprints analysis](https://jazzomat.hfm-weimar.de/dbformat/synopsis/solo431.html). Source selection and pulse interpretation are documented per entry; no external audio is downloaded or bundled.
